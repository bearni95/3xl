# Character Moves

Each character gets defined 3 moves:
- melee
- ranged
- final

ranged and final define a projectile


each of the moves, bound to each character, gets special effects, such as destroying with their projectile as it advances, or being a shaped explosion. melee moves also get these.
this makes each character mechanically unique, even if a tat more involved

then, each character gets a base ratio of atk, def and hp
- atk is a pool of d10 that's roll on attack
- def is the nummber required to hit the creature, max is 10
- hp is a pool of d10, rolled at each combat start
